# RMS iQor México — Sitio Web Oficial

Sitio web corporativo y plataforma de captación de leads para **RMS iQor México** (CXBPO, cobranza extrajudicial, legal y administrativa, y capital humano).

---

## 🚀 Tecnologías

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, React 19)
- **Lenguaje**: [TypeScript](https://www.typescriptlang.org/)
- **Animaciones & Motion**: [GSAP](https://greensock.com/gsap/) + [Lenis](https://lenis.darkroom.engineering/) Smooth Scroll
- **Estilos**: Vanilla CSS Moderno / Design Tokens personalizados
- **SEO & Structured Data**: Schema.org JSON-LD (Organization, LocalBusiness, FAQPage)

---

## 📦 Instalación y Desarrollo

1. **Instalar dependencias**:
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo**:
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en el navegador.

3. **Construir para producción**:
   ```bash
   npm run build
   ```

4. **Ejecutar linter**:
   ```bash
   npm run lint
   ```
